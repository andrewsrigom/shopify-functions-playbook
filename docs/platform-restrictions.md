# Platform restrictions checked on 2026-09-16

All core examples use **2026-04 run targets**. There are no fetch targets. Function runtime code has no filesystem, current-time, or arbitrary network dependencies.

| API                          | Owner / activation                                  | Coexistence and specific restrictions                                                                                                                                                                                |
| ---------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cart and checkout validation | Validation / validationCreate and validationUpdate  | Versioned reference permits up to 25 active validation Functions; expected errors block checkout. blockOnFailure separately governs runtime failure behavior.                                                        |
| Discount                     | Automatic app discount / discountAutomaticAppCreate | Unified Discount API; up to 25 discount Functions. Independently executed, with combinations controlled on the discount owner. No legacy product/order/shipping discount APIs.                                       |
| Payment customization        | PaymentCustomization / create/update                | Up to 25. This example hides a named available method. Specific placements, payment terms, and order review have additional restrictions and are not used.                                                           |
| Delivery customization       | DeliveryCustomization / create/update               | Up to 25. Rename, hide, or reorder available options; no rate creation or price changes. Verify checkout surface and other installed customizations.                                                                 |
| Cart Transform               | CartTransform / create/delete                       | One transform per app per store in the checked reference; other apps can also transform lines. Selling plans are incompatible with expand/merge/update. lineUpdate needs development stores or Plus and is not used. |

Public apps containing Functions are available across supported plans. Custom apps containing Function APIs require Plus on production stores. Use a development store with the required capabilities and app-development permissions for live testing. Supported checkout surfaces and API behavior can differ; the per-scenario references are authoritative.

Network access is separately gated and must be requested. The checked validation reference limits fetch to custom apps on Enterprise stores; the discount reference lists custom apps on Plus/Enterprise. Development stores do not provide the network-access target. These restrictions are not obstacles for the run-only examples here. Do not infer that ordinary Function code can perform HTTP calls.

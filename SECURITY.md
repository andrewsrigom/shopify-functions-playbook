# Security considerations

These examples contain no credentials. Do not commit app tokens, environment files, private customer payloads, or CLI session data. Use a development store for activation and checkout verification.

Configuration is app-owned and checked at runtime. Invalid configuration currently returns no operations. That policy is explicit and must be reviewed before using a validation for a mandatory business restriction.

This repository does not operate a vulnerability bounty program or claim Shopify support commitments. Report platform vulnerabilities through Shopify’s official channels; review and fix example-specific issues in your own maintained copy.
